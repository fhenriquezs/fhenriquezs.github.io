Política de privacidad

gmail-mcp es una aplicación de uso personal. Accede a Gmail mediante la API de Google con el permiso gmail.modify, únicamente en cuentas autorizadas por su propietario.

Datos a los que accede

Mensajes, hilos, etiquetas y borradores de las cuentas autorizadas, solo cuando el propietario lo solicita.

Cómo se usan y almacenan

  • Toda la ejecución ocurre localmente en el computador del propietario.
  • Los tokens de acceso se guardan localmente con permisos restringidos y nunca se transmiten a servidores propios ni de terceros.
  • No se recopilan, venden ni comparten datos con terceros, ni se usan para publicidad.
  • La aplicación no envía ni elimina correos.

El uso de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Revocar el acceso

El acceso puede revocarse en cualquier momento desde myaccount.google.com/permissions.
